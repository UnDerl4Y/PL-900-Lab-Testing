# PL-900 Lab Testing

Testing PL-900 lab instructions against the current Microsoft Power Platform experience.

## Objective

Identify outdated instructions, missing steps, and blockers to ensure students can complete the labs successfully.

## Lessons Learned

First testing run: I documented findings separately instead of directly updating the original instructions. Lesson learned: findings should lead to fixes.

## Next Time

1. Follow the instructions as written.
2. Update the original instructions directly.
3. Pause and ask for clarification or permissions when blocked.
4. Re-test after making changes.
